# MCM Chromatic Time & Weather

A sleek, mid-century modern inspired website displaying real-time and San Francisco weather with a vibrant chromatic design.

## Features

✨ **Chromatic MCM Design** - Animated gradient background with retro color palette
🕐 **Real-time Clock** - Updates every second with current time and date
🌤️ **SF Weather Display** - Live weather data with temperature, humidity, and wind speed
🎨 **Glassmorphism UI** - Modern frosted glass effect on cards
📱 **Responsive Design** - Works on desktop and mobile devices

## Technology

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with animations and gradients
- **JavaScript** - Dynamic time updates and weather API integration
- **Open-Meteo API** - Free weather data (no API key required)

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Enjoy the chromatic time and weather display!

## Files

- `index.html` - Main HTML structure
- `styles.css` - All styling and animations
- `script.js` - Time updates and weather API integration

## Weather Data

Weather data is fetched from the Open-Meteo API which provides free weather forecasts without requiring an API key. Data updates every 10 minutes.
